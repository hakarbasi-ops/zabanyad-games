# بازی‌های تخفیف زبانیاد

کاربر یک بازی کوچک انجام می‌دهد و اگر برنده شود، یک کد تخفیف واقعی روی شماره موبایلش در زبانیاد ساخته می‌شود.

| بازی | نشانی | جایزه |
| --- | --- | --- |
| 🎡 گردونه شانس | `/g/wheel` | هر خانه یک جایزه با وزن شانس خودش |
| 🎟️ کارت خراشی | `/g/scratch` | مثل گردونه، با کارتی که با انگشت خراشیده می‌شود |
| 🔤 چالش کلمه | `/g/words` | ۵ کلمه‌ی انگلیسی در ۶۰ ثانیه؛ هرچه جواب درست بیشتر، تخفیف بیشتر |

- پنل مدیریت: `/admin` (رمز = `ADMIN_PASSWORD`)
- فهرست بازی‌های فعال: `/`

## پنل

- **داشبورد:** تعداد بازی‌ها، بازیکن‌ها، کدهای ساخته‌شده، نمودار ۱۴ روز اخیر و آمار هر جایزه.
- **بازی‌ها و جایزه‌ها:** برای هر بازی می‌شود این‌ها را تنظیم کرد:
  - روشن یا خاموش بودن، زمان شروع و پایان، رنگ، متن و قوانین
  - تعداد دفعات بازی هر شماره (مثلاً یک بار، یا هفته‌ای یک بار)
  - مدت اعتبار کد و سقف تعداد کد در روز
  - برای هر جایزه: درصد یا مبلغ، سقف تخفیف، دفعات استفاده، وزن شانس (یا حداقل جواب درست در چالش کلمه) و موجودی
  - در چالش کلمه: فهرست کلمه‌ها

  بازی تازه از هر سه نوع هم از همین‌جا ساخته می‌شود.
- **بازی‌کنندگان و کدها:** جستجو بر اساس موبایل یا کد، و خروجی اکسل.
- **اتصال به زبانیاد:** وضعیت اتصال و دکمه‌ای برای ساخت یک کد آزمایشی.

## چطور کار می‌کند

- **نتیجه را فقط سرور تعیین می‌کند.** گوشی کاربر فقط انیمیشن را نشان می‌دهد، پس با دستکاری صفحه نمی‌شود جایزه‌ی بزرگ‌تر گرفت.
- **ساخت کد:** کد با API زبانیاد ساخته می‌شود (`POST generateDiscountForUser` با هدر `X-Client-Secret`). اعتبار کد از همان لحظه تا پایان روزِ N روز بعد است.
- **کاربر ثبت‌نام نکرده:** اگر زبانیاد شماره را پیدا نکند (404)، به کاربر گفته می‌شود اول ثبت‌نام کند. آن دست حساب نمی‌شود و جایزه هم به موجودی برمی‌گردد.
- **خطای API:** در این حالت هم آن دست حساب نمی‌شود.
- **محدودیت‌ها:** تعداد بازی هر شماره، تعداد بازی از هر IP در ساعت، و موجودی و سقف روزانه‌ی کدها.

## اجرا

نصب روی سرور آروان: `docs/deploy-fa.md` (بدون نیاز به اینترنت خارج؛ `deploy/install.sh`).

با Docker (جایی که Docker Hub در دسترس است):

```bash
cp .env.example .env        # ADMIN_PASSWORD و DISCOUNT_API_SECRET را روی سرور پر کنید
docker compose up -d --build
```

پس از اجرا، برنامه روی `127.0.0.1:8000` در دسترس است. نمونه‌ی تنظیم nginx در `deploy/nginx.conf` است. بدون Docker هم می‌شود اجرا کرد: یک venv بسازید، `pip install -r requirements.txt` را اجرا کنید و از `deploy/zabanyad-games.service` استفاده کنید.

اگر `DISCOUNT_MODE=mock` باشد، کدها ساختگی‌اند (با T شروع می‌شوند) و چیزی به زبانیاد فرستاده نمی‌شود. این حالت برای امتحان بازی‌هاست.

کلید API فقط در فایل `.env` روی سرور قرار می‌گیرد. هیچ‌وقت در مخزن، چت یا لاگ نوشته نمی‌شود.

## توسعه

```bash
python -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
pytest
ADMIN_PASSWORD=demo uvicorn app.main:app --reload
```

ساختار پروژه:

- `app/games.py`: قوانین بازی، قرعه، موجودی، چالش کلمه
- `app/discount.py`: اتصال به API زبانیاد
- `app/admin.py`: API پنل
- `app/db.py`: SQLite و داده‌ی اولیه
- `static/`: صفحه‌های بازی و پنل (JS ساده، بدون مرحله‌ی build)
