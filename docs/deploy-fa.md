# نصب بازی‌ها روی سرور آروان (games.zabanyad.com)

## ۱. مشخصات سرور

| | حداقل | پیشنهادی (کمپین‌های پرمخاطب) |
| --- | --- | --- |
| پردازنده | ۱ هسته | ۲ هسته |
| حافظه (RAM) | ۱ گیگابایت | ۲ گیگابایت |
| دیسک | ۲۰ گیگابایت | ۲۵ گیگابایت |
| سیستم‌عامل | Ubuntu 24.04 | Ubuntu 24.04 |
| شبکه | IP عمومی؛ پورت‌های ۲۲ و ۸۰ باز | همین |

- سرور به اینترنت خارج نیاز ندارد. همه‌ی بسته‌ها داخل فایل نصب هستند.
- سرور فقط باید به `api.zabanyad.com` دسترسی داشته باشد.

## ۲. دامنه

در پنل DNS دامنه‌ی zabanyad.com یک رکورد بسازید:

- نوع: `A`
- نام: `games`
- مقدار: IP سرور

اگر DNS دامنه روی CDN آروان است:

- پروکسی (ابر نارنجی) را روشن کنید.
- در بخش HTTPS، گواهی SSL آروان را فعال کنید.
- پروتکل ارتباط با سرور اصلی را **HTTP** بگذارید. سرور روی پورت ۸۰ جواب می‌دهد.

## ۳. نصب

فایل `zabanyad-games-<شماره>.zip` را روی سرور کپی کنید:

```bash
scp zabanyad-games-1.zip root@IP-سرور:/root/
```

بعد وارد سرور شوید و نصب را اجرا کنید:

```bash
ssh root@IP-سرور
cd /root && python3 -m zipfile -e zabanyad-games-1.zip /root/
bash /root/zabanyad-games/deploy/install.sh
```

بار اول، نصب دو چیز می‌پرسد. هیچ‌کدام روی صفحه نمایش داده نمی‌شود:

- **رمز پنل:** حداقل ۸ حرف.
- **کلید API زبانیاد** (`X-Client-Secret`): اگر هنوز ندارید، Enter بزنید. بازی‌ها در این حالت فقط کد آزمایشی می‌دهند.

بعد از آن، کلید API و نام الگوی کاوه‌نگار را برای پیامک کد تأیید می‌پرسد. الگو را یک بار در پنل کاوه‌نگار (بخش «اعتبارسنجی / الگوها») با متنی مثل «کد تأیید بازی‌های زبانیاد: %token» بسازید و بعد از تأیید کاوه‌نگار، نامش را وارد کنید.

برای عوض کردن رمز یا کلیدها در آینده:

```bash
bash /opt/zabanyad-games/deploy/set-credentials.sh
```

## ۳٫۵. فعال کردن HTTPS (گواهی رایگان)

روی سرور بزنید:

```bash
sudo bash /opt/zabanyad-games/deploy/enable-https.sh
```

- یک ایمیل می‌پرسد (برای هشدار انقضا). می‌توانید Enter بزنید.
- اول از راه معمول (بررسی از طریق پورت ۸۰) گواهی می‌گیرد. برای این کار رکورد `games` باید به IP سرور اشاره کند.
- اگر نشد (معمولاً چون ترافیک خارج به سرور ایرانی نمی‌رسد)، پیشنهاد راه دوم را می‌دهد: بررسی از طریق DNS کلودفلر با یک «API Token».
  - در Cloudflare: My Profile ← API Tokens ← Create Token ← قالب «Edit zone DNS» ← zone: zabanyad.com
  - توکن را همان‌جا روی سرور وارد کنید، نه در چت.
- گواهی خودکار تمدید می‌شود و با به‌روزرسانی‌ها از بین نمی‌رود.
- اگر ابر نارنجی کلودفلر روشن است، SSL را روی **Full (strict)** بگذارید.

## ۴. بعد از نصب

۱. نشانی `https://games.zabanyad.com/admin` را باز کنید و با رمز وارد شوید.

۲. در «اتصال به زبانیاد» با شماره‌ی خودتان یک کد آزمایشی با درصد کم بسازید. اگر کد ساخته شد، اتصال درست است.

۳. در «بازی‌ها و جایزه‌ها» برای هر بازی این‌ها را تنظیم کنید:
   - جایزه‌ها (مبلغ‌ها به **ریال**)
   - شانس هر جایزه
   - تعداد دفعات بازی هر شماره

   بعد تیک «بازی فعال باشد» را بزنید.

۴. لینک بازی‌ها را در اینستاگرام یا اپ بگذارید:
   - `https://games.zabanyad.com/`
   - `https://games.zabanyad.com/g/wheel`
   - `https://games.zabanyad.com/g/scratch`
   - `https://games.zabanyad.com/g/words`

## به‌روزرسانی

فایل zip جدید را کپی کنید و همان دستورهای بخش ۳ را با نام فایل جدید اجرا کنید. اطلاعات بازی‌ها، رمز و کلید حفظ می‌شوند.
